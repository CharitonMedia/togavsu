# Togavsu license in plain English

This summary is not the license; [LICENSE](LICENSE) is.

- **Your firm can use Togavsu for free.** Download it, install it, run it for real client work and change the code, at no charge, for your own firm's practice.
- **The source is public, but Togavsu is not open source.** It's source-available: you can read, modify and share the code under these terms.
- **Hosting Togavsu for other firms costs money.** If you host Togavsu commercially, or run it for firms other than your own, you need a commercial license from Chariton Media: $500 a year plus $2 per seat per month for every seat you serve. The admin dashboard shows the active seat count so you can bill from it.
- **These terms don't expire.** There's no date on which Togavsu turns into open source.
- **There are no license keys.** Togavsu never phones home to check a license.
- **Modules have their own terms.** A module's author sets its license and price. The marketplace can flag or pull a module, but that never takes away code a firm already has.
- **No warranty.** Togavsu comes as is.
