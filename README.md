# Togavsu

Practice management core for solo and small law firms. Approved scope: [core PRD](togavsu-core-prd.md).

Build setup: Cursor Cloud Agents implement bounded assignments; GitHub holds branches, CI and recovery points; Codex independently reviews checkpoints.

Read [build workflow](docs/build/WORKFLOW.md) and [agent instructions](AGENTS.md).
The repository currently contains build setup, not a completed application. Initial source is private while development is prepared; release licensing and distribution follow the PRD.
