# Togavsu

Practice management core for solo and small law firms. Approved scope: [core PRD](togavsu-core-prd.md).

Build setup: Cursor Cloud Agents implement bounded assignments; GitHub holds branches, CI and recovery points; Codex independently reviews checkpoints.

Read [build workflow](docs/build/WORKFLOW.md) and [agent instructions](AGENTS.md).
The repository currently contains build setup, not a completed application. Source is public as specified in the PRD; release licensing and distribution follow its terms.

[Build tracking](docs/build/TRACKING.md) links the initial assignments and seven-phase tracking issue. All 52 acceptance criteria are indexed; product implementation and acceptance remain pending.
